# NeetCode Daily DSA

This repository contains my daily solutions to **NeetCode and LeetCode
Data Structures & Algorithms problems**, solved primarily in **C++**.

The goal of this repository is to build consistency, improve problem-solving
skills, and develop a strong understanding of common DSA patterns used in
coding interviews and technical assessments.

##  Topics Covered

- Arrays & Hashing
- Two Pointers
- Sliding Window
- Stack
- Binary Search
- Linked List
- Trees
- Tries
- Heap / Priority Queue
- Backtracking
- Graphs
- 1-D Dynamic Programming
- 2-D Dynamic Programming
- Greedy
- Intervals
- Math & Geometry
- Bit Manipulation

## Goals

- Solve DSA problems consistently every day
- Understand problem-solving patterns rather than memorizing solutions
- Improve time and space complexity analysis
- Strengthen C++ programming skills
- Prepare for coding interviews and placement assessments
- Track my progress throughout my DSA journey

## Language

- C++
